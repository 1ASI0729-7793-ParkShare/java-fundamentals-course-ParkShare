1. Introducción y Bienvenida (0:00 - 1:00 min)

"¡Hola a todos y bienvenidos a este curso de fundamentos de Java! ¿Alguna vez te has preguntado cómo funcionan tus videojuegos favoritos, las aplicaciones de tu teléfono o las páginas web que usas todos los días? Todo eso funciona gracias a la programación. Programar no es magia, es simplemente darle instrucciones paso a paso a una computadora para que haga lo que nosotros queremos. ¡Imagina que es como escribir una receta de cocina!"

2. ¿Qué es Java y por qué lo usamos? (1:00 - 2:30 min)

"Existen muchos lenguajes de programación, pero hoy nos enfocaremos en Java. Java es uno de los lenguajes más populares, potentes y utilizados del mundo entero. Lo usan grandes empresas para crear aplicaciones móviles, sistemas bancarios y videojuegos masivos como Minecraft. Lo mejor de todo es que no necesitas instalar nada en tu computadora; solo usaremos tu navegador web."   

3. Demostración Práctica en Línea: Hola Mundo (2:30 - 4:30 min)

"Vamos a ver nuestro primer programa en acción. Abre el enlace que dejamos en la descripción del video para ingresar directamente a OnlineGDB. Al entrar, verás un espacio de trabajo como este:"   

Java
// Código base para OnlineGDB - Lección 1
public class Main {
    public static void main(String[] args) {
        System.out.println("¡Hola, mundo! Bienvenidos a la programación con Java.");
    }
}

"Fíjate en las líneas de código. System.out.println es la orden que le damos a Java para que imprima un mensaje en la pantalla. Si hacemos clic en el botón verde 'Run' (Ejecutar) en OnlineGDB, veremos el texto aparecer instantáneamente en la consola de abajo. ¡Acabas de ejecutar tu primer programa de código!"
